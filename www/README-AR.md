# مشروع جمعية إدزاح إدبوكا — النسخة المنظمة

## طريقة الاستخدام
- ارفع محتويات هذا المجلد إلى مجلد `www` في مستودع GitHub مع الحفاظ على المسارات.
- ملف التشغيل الرئيسي هو `index.html`.
- ملفات التنسيق في `assets/css/`.
- السكربت الأساسي المستخرج بأمان في `assets/js/core-application.js`.
- التعديلات والوظائف الإضافية المستقلة في `assets/js/modules/`.
- `population-window-reference.html` نسخة مرجعية مستقلة لنافذة الساكنة وليست جزءاً يُحمّل تلقائياً داخل التطبيق.

## ملاحظات مهمة
1. تم استخراج كتل JavaScript وCSS من ملف HTML مع الحفاظ على ترتيب ظهورها الأصلي، حتى لا تتغير أسبقية التنسيقات أو ترتيب تهيئة الوظائف.
2. لم تُعد كتابة منطق قاعدة البيانات أو مفاتيح التخزين أو أسماء الدوال.
3. ملف `core-application.js` ما زال يحتوي على المنطق الأساسي الكبير. تركه كما هو في هذه المرحلة إجراء احترازي؛ الخطوة التالية هي تقسيمه تدريجياً حسب الوظائف بعد تحديد اعتماديات كل نافذة واختبارها.
4. لا ترفع ملف HTML المرجعي للساكنة كصفحة تشغيل إضافية إلا إذا كنت تريد فتحه مستقلاً.
5. اختبر النسخة على نسخة تجريبية من GitHub Pages قبل استبدال النسخة المنشورة.

## البنية
- `index.html` — الهيكل الرئيسي.
- `assets/css/app.css` — جميع التنسيقات المستخرجة بالترتيب.
- `assets/js/core-application.js` — التطبيق الأساسي.
- `assets/js/modules/` — إضافات منفصلة (الماء، الاجتماعات، الساكنة...).
